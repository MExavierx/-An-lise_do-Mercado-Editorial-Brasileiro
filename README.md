# 📚 Análise de Mercado Editorial

Projeto de análise de dados sobre livros e rankings de vendas, desenvolvido a partir de dados da PublishNews.

## 📊 Dados

- **Período analisado:** 30/06/2025 a 17/08/2025
- **Períodos coletados:** 7 semanas
- **Duração do recorte:** 1 mês e 18 dias

## 🗄️ Banco de dados

O projeto utiliza um banco de dados relacional para organizar informações sobre:

- Livros
- Autores
- Editoras
- Categorias
- Vendas

## 📚 Conceitos de SQL

Durante o desenvolvimento, serão trabalhados conceitos como:

- `CREATE TABLE`
- `INSERT`
- `SELECT`
- `WHERE`
- `JOIN`
- `GROUP BY`
- `ORDER BY`
- `UPDATE`
- Funções de agregação

### 🎯 Objetivos

* Praticar modelagem de banco de dados;
* Trabalhar com relacionamentos e chaves estrangeiras;
* Desenvolver consultas SQL para análise dos dados;
* Explorar padrões e tendências do mercado editorial.

Mais análises e consultas serão adicionadas conforme o desenvolvimento do projeto.
